# Bike-Rental-Analysis
Melakukan analisis terhadap pola penyewaan sepeda pada tahun 2011 sampai 2012.
Menggunakan Python untuk melakukan analisis dan Streamlit untuk pembuatan visualisasi dashboard.

Dataset : [Bike Sharing Dataset](https://www.kaggle.com/datasets/lakshmi25npathi/bike-sharing-dataset)

## Langkah Pembuatan Projek
1. Data Wrangling
2. Exploratory Data Analysis (EDA)
3. Data Visualization & Explanatory Analysis
4. Dashboard Development using Streamlit

## Akses Dashboard Streamlit
Link : [Streamlit Dashboard](https://dashboard-bike-rental-analysis.streamlit.app/)

## Menjalankan Dashboard secara Lokal
1. Clone repository
   ```
   https://github.com/NurillahT/Bike-Rental-Analysis.git
   ```
2. Masuk ke directory
   ```
   cd Bike-Rental-Analysis-main\dashboard
   ```
3. Install library
   ```
   pip install -r requirements.txt
   ```
4. Jalankan streamlit
   ```
   streamlit run dashboard.py
   ```
